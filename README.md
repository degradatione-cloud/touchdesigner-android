# TouchDesigner для Android (node-патчер)

> **Небольшой проект для портирования.** Идея TouchDesigner — граф операторов, каждый делает
> одну операцию с картинкой — перенесена на телефон: узлы, связи, GLSL-проходы в FBO,
> живое превью и feedback между кадрами. Официальный TouchDesigner проприетарный и под
> Windows/macOS, здесь — своя реализация той же модели.

## Что умеет (0.1)

- **Граф как в TD**: `Gradient`, `Noise`, `Blur`, `Kaleido`, `Twist`, `Mirror`, `Colorize`,
  `Feedback`, `Blend`, `Output`. У каждого узла свой фрагментный шейдер и свой FBO.
- **Feedback** — настоящий кадровый аккумулятор с распадом и зумом (ping-pong FBO).
- **Живое превью** на GLES 2.0, счётчик FPS, пауза/воспроизведение времени.
- **Патч-редактор**: узлы тащатся пальцем, связи — тапом по портам (выход → вход),
  панорама фона, сетка. «Столбец» раскладывает сеть под узкий экран.
- **Пресеты**: Плазма, Вихрь, Зеркало.
- **Снимок** превью в `Pictures/TouchDesigner`.
- Сеть сохраняется/читается в JSON (`Patch.toJson/loadJson`) — основа для шаринга патчей.

## Как это устроено

```
UI (Compose)  →  Patch (узлы, связи, порядок вычисления)
                      ↓
              GlEngine.onDrawFrame
                      ↓
   узел 1 → FBO 1 → узел 2 → FBO 2 → … → Output → экран
```

- Разрешение рендера ограничено 1080 по длинной стороне — телефон не греется зря.
- Feedback держит два FBO и меняет их местами каждый кадр.
- Тесты: `./gradlew :app:testDebugUnitTest` — пресеты, связи, self-link, JSON-раундтрип, раскладка.
